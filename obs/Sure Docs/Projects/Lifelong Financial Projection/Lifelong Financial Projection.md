# lucide-telescope Lifelong Financial Projection

Expand Sure's Rails web application and API from historical financial tracking into a comprehensive lifelong planning system: current-finance baselines, scenario plans, milestones, cash-flow simulation, investments, taxes, benefits, uncertainty, optimization, estate planning, international rules, and progress tracking.

## Confirmed product decisions
- Pursue comprehensive planning outcomes using Sure-native terminology, defaults, workflows, and connected-data advantages.
- Limit scope to personal and household financial-planning capabilities; exclude advisor, employer, subscription, gift, billing, and directory functionality.
- Deliver functionality through the Rails web application and a documented API. Desktop and mobile clients are consumers of those contracts, not separate deliverables here.
- Make planning available to all Sure users and self-hosted deployments without premium entitlements.
- Treat this as a multi-year program with coherent staged releases.
- Make the United States the first production-grade tax and benefit jurisdiction; add other countries after the core is proven.
- Target explainable planning-grade estimates, not tax-return preparation or filing accuracy.
- Keep this project independent from `Sure Alt Frontend`, with explicit contract touchpoints and no UI implementation tasks.
