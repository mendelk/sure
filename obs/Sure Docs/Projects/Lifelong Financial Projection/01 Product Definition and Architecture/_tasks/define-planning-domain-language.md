Define Sure-native concepts for plans, starting conditions, people, events, flows, milestones, assumptions, tax jurisdictions, trials, strategies, progress points, and estate outcomes.

## Acceptance criteria
- Terms have precise meanings, ownership rules, time semantics, units, and lifecycle states.
- Existing Sure concepts such as Family, Account, Goal, Budget, Balance, Holding, Transaction, Transfer, and Valuation remain authoritative where appropriate.
- Similar but different concepts are explicit, including budget versus projection, goal versus milestone, transaction versus simulated flow, and current balance versus plan starting balance.
- The language supports individuals, couples, dependents, household collaborators, and API consumers using consistent Sure-native naming.
- A glossary prevents calculations, APIs, documentation, and user-facing explanations from using contradictory terms.

## Verification
- Walk representative accumulation, retirement, survivor, relocation, and estate scenarios through the vocabulary without ambiguous objects or ownership.
