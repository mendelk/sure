Journal actual household financial snapshots and compare them with what a fixed-date plan projected for the same dates.

## Acceptance criteria
- Progress points can be created manually or automatically when current finances are updated, with optional automation per household.
- Points retain dated asset, liability, account, and net-worth detail rather than only one total.
- Fixed-date plans overlay actual progress after intra-year inflation proration and comparable-currency conversion.
- Variance reports distinguish changed starting facts, actual market performance, cash flow, and changed plan assumptions where possible.
- Users can update a living plan without erasing the original baseline used to measure progress.

## Verification
- Multi-year fixtures cover automatic/manual points, corrected history, inflation, mixed currencies, and plan updates.
